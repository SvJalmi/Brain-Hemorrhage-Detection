7. IMPORTANT ML IMPLICATIONS
----------------------------------------------------------------------
1. Do not perform a naive image-level random train/validation/test split.
   The dataset contains repeated filenames, augmentation variants,
   multiple folder placements, and shared image IDs.

2. Use image ID as a grouping signal when constructing splits.
   All files sharing the same image ID should remain in the same
   split unless a stronger verified patient-level identifier is available.

3. Do not treat folder membership as proof of independent patients.
   The same image ID occurs across multiple folders.

4. Do not delete the 3,242 unlogged Intraventricular files merely
   because they are absent from the CSV. They are byte-identical
   duplicates of logged Intraventricular files and are part of
   the original physical dataset.

5. Do not rename or delete Epidural nan.png at this stage.
   It is a valid PNG but is anomalous with respect to the CSV.

6. Do not resize, delete, or modify the 32 non-512x512 images merely
   because their dimensions differ. All were readable and passed
   the image-integrity checks.

7. The raw dataset should remain untouched. Any cleaning or
   preprocessing should be performed in a separate derived dataset.
