============================================================
9. DATA LEAKAGE CONSIDERATION
============================================================

The dataset contains exact duplicate images and
augmentation-derived images.

Therefore, a naive image-level random train/validation/test
split should NOT be used.

Related duplicate and augmentation images should be kept
within the same data split during future experiments.

The duplicate metadata report is stored at:

dataset_check\tbi6000_duplicate_metadata.csv

============================================================
11. FINAL AUDIT CONCLUSION
============================================================

TBI-6000 PASSES the basic raw image integrity audit.

The dataset contains no detected corrupted, unreadable,
blank, or constant-value images.

However, the following characteristics must be documented
and considered during experimental design:

1. One image has dimensions 512 x 666.
2. There are 47 exact duplicate groups involving 97 files.
3. Four groups contain pixel-identical images with different IDs.
4. 723 files are explicitly marked as augmented.
5. All explicitly augmented files are in the epidural class.
6. Patient-level independence cannot be established from
   filenames alone.

Therefore, TBI-6000 is suitable for continued research use,
provided that duplicate/augmentation relationships are
considered when constructing experimental data splits.
